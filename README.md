# best-game-01

STARWAKE — Comet Courier: an original arcade game of gravity, shards and delivery. Pilot your
courier ship through a field of glowing gravity wells, herd stardust shards home to the gate,
and dodge the asteroid belt across escalating waves. Keyboard + mouse, procedural WebAudio,
fully offline static files.

## Run it

```sh
node serve.ts        # serves game/ on http://localhost:8080
```

Or run the entry program (copies game/ + screenshots/ and writes dossier.json):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Play: arrows/WASD to thrust and steer, mouse to aim, click to dash, P pause, M mute, R restart.
